# 🥗 Навигатор питания

PWA для людей с заболеваниями кишечника. Информационный помощник, не заменяет врача.

## Что внутри

- Анкета + расчёт BMR (Mifflin → Katch-McArdle → измеренный)
- Профиль здоровья (фаза ремиссия/обострение)
- Справочник продуктов + свои «разрешённые/запрещённые»
- Планировщик на 4 приёма (граммы сырого веса)
- Дневник питания + симптомов
- Red-flag детекция
- Голосовое сообщение + голосовой ввод
- Локальное хранилище (никаких серверов)
- Работает офлайн (Service Worker)
